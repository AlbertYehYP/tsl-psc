# 編號規則

依據「TSL 事故通報標準範本與追蹤編號系統（修訂版 2.0，2026/02/12）」，並加上 PSC 專用規定（2026/10 決議）。

## 1. 事故追蹤編號

```
[公司碼]-[船名]-[YYYYMMDD]-[等級][類型]-[序號]
FLEET-TS KOBE-20260911-3O-01
```

| 欄位 | 規則 |
|---|---|
| 公司碼 | `FLEET`、`VSHIPS`、`BSM`、`TSL`（自管）、`TEH`。依「船隊資料」在事故日期當天有效的那一筆帶入 |
| 船名 | 英文全大寫，與船隊資料一致，不加多餘空白 |
| YYYYMMDD | 事故日期（當地日期）；PSC 用檢查日期 |
| 等級 | `1` Major、`2` Moderate、`3` Minor |
| 類型 | `M N C P E S F T O`；PSC 一律 `O` |
| 序號 | 同船同日第幾件事故，01–99；PSC 與非 PSC 合併計算 |

編號一經發出就不再變更。之後若等級改變（例如補登留置），系統會更新事故登錄的等級欄並提示註記，但編號維持原樣。

## 2. PSC 等級判定

依序檢查，符合第一個條件就停止：

1. 有留置（勾選「被留置」或任一缺失處理代碼為 30）→ **Tier 2**
2. 缺失項數 ≥ 門檻（預設 6）→ **Tier 2**
3. 有 ISM 缺失（代碼 15xxx），且設定為「開出 ISM 缺失即升級」→ **Tier 2**
4. 其他有缺失 → **Tier 3**
5. 無缺失 → **NIL**，不立事故編號

門檻與 ISM 規則可在「系統管理 → 編號與等級設定」調整，只影響之後新登錄的案件。

## 3. 時限（依等級）

| 等級 | 立即通報 | 正式初步報告 | 最終調查報告 RCA |
|---|---|---|---|
| 1、2 | 2 小時 | 24 小時 | 14 天 |
| 3 | 12 小時 | 48 小時 | 21 天 |

案件頁會依已上傳的文件（FLASH、INIT、RCA）顯示是否已歸檔或逾期。

## 4. 其他編號

| 項目 | 格式 | 範例 |
|---|---|---|
| PSC 檢查編號 | `PSC-[YYYYMMDD]-[IMO]` | `PSC-20260922-9854844` |
| 缺失編號 | `[事故編號]-D[序號]`；NIL 無缺失 | `FLEET-TS KOBE-20260911-3O-01-D03` |
| 文件編號 | `[事故編號]_[文件代碼]_[序號]` | `FLEET-TS KOBE-20260911-3O-01_RECT_01` |
| 檔名 | 文件編號＋原副檔名 | `FLEET-TS KOBE-20260911-3O-01_RECT_01.pdf` |

## 5. 文件代碼

| 代碼 | 文件 |
|---|---|
| PSC-A | PSC 檢查報告（Form A） |
| PSC-B | PSC 缺失清單（Form B） |
| RECT | 船舶矯正報告 |
| EVID | 矯正佐證（照片／證書） |
| FLASH | 立即通報（Template 1A–1C） |
| INIT | 正式初步報告（Template 2） |
| UPD | 進度更新（Template 3） |
| RCA | 最終調查報告（Template 4） |
| CLOSE | 結案確認（Template 5C） |
| CORR | 往來信件 |
| OTH | 其他 |

## 7. 歷史資料

- 2026 年以前的 PSC 檢查標為「歷史資料」，不補發事故編號。
- 事故登錄器的 97 筆既有編號保留原樣。
  - 格式有問題的，在 `tracking_no_std` 欄列出建議寫法，並在 `check_notes` 註記問題。
- 2026 年 4 次有缺失但未立案的 PSC 檢查，標為「未立案」：
  - TS QINGDAO 1/29 香港
  - TS SHEKOU 1/29 深圳
  - TS TOKYO 2/19 仁川
  - TS MELBOURNE 8/13 雪梨

## v1.1 補充：非 PSC 事故的文件與期限

- 非 PSC 事故的文件同樣命名為 `[事故編號]_[文件代碼]_[序號].[副檔名]`，歸檔在 `事故/[年]/[事故編號]/`。
- 文件代碼多了 `RPT`（船方事故報告）；`PSC-A`、`PSC-B` 只能用在 PSC 事故。
- 新事故建立時寫入 `flash_due`、`initial_due`、`rca_due`；舊資料沒有這三欄時依事故日期與等級推算（嚴重程度碼不在規則內時以 Tier 3 計）。
